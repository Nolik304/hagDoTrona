# Аудит «Бездна Idle»

## Проверено

- `npm run typecheck` проходит.
- `npm run build` проходит.
- Игровой прогресс сохраняется в `localStorage`, есть миграция версии `v1` и офлайн-награда максимум за 8 часов.
- VK Mini Apps bridge подключён через отдельный адаптер с fallback для обычного браузера.
- Ссылка приложения настроена на `https://vk.ru/app54071751`.
- GitHub Actions проверяет типы и production-сборку на push и pull request.

## Риски и следующие шаги

1. Прогресс хранится только в браузере. Очистка данных, другой браузер или другое устройство сбрасывают игру. Для синхронизации нужен серверный профиль VK и авторизация через `VKWebAppGetUserInfo`.
2. Сохранение принимает JSON из `localStorage` после минимальной проверки. Для публичного релиза стоит добавить схему валидации и миграции для каждого изменения модели.
3. Экономика и боевой баланс не покрыты автоматическими тестами. Стоит вынести тесты reducer/формул и добавить проверки наград, смерти, офлайн-прогресса и переходов зон.
4. GitHub remote не настроен: для подключения хранилища нужен URL созданного репозитория. После его получения достаточно выполнить `git remote add origin <URL>` и отправить ветку `master`.
